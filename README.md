# À première vue

Entraînement à la lecture de notes : **150 notes, 3 minutes**. Version web installable sur iPhone, adaptée de l'appli Mac « À première vue » (v0.6). Le clavier et la charte graphique viennent de [Clé de lecture](https://github.com/LateValencia/cle-de-lecture).

## Règles

- +1 par note juste **à la bonne octave**, −1 par erreur ; la note reste active tant qu'elle n'est pas trouvée.
- 130 points débloquent le niveau suivant (★ dès 130, ★★ dès 140, ★★★ à 150).
- La séance s'arrête dès que les 130 points ne sont plus atteignables.
- Douze notes par ligne (3 mesures de 4 noires) ; la ligne suivante apparaît pendant la dernière mesure.

## Niveaux (par clé)

1 à 7 : tessiture qui s'élargit (clé de sol à partir de Do4–Sol4, clé de fa à partir de Mi2–Si2), jusqu'à trois lignes supplémentaires. 8 : deux portées. 9 : changements de clé. 10 : octaves 8va / 8vb.

## Clavier

Le clavier n'affiche que les octaves utiles au niveau : une octave par rangée (grandes touches) jusqu'à 3 octaves, puis deux octaves par rangée. L'aigu est en haut, le do central porte une pastille.

## Installer sur iPhone

Ouvrir l'adresse GitHub Pages dans Safari, puis Partager → « Sur l'écran d'accueil ». Tout fonctionne en local : la progression et les 200 dernières séances restent sur l'appareil. Le son passe par le haut-parleur (désactiver le mode silencieux si besoin).
